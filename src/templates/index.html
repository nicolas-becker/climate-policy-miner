How the analysis pipeline works

The tool follows a four-step AI pipeline that turns climate policy PDFs into structured, traceable transport insights.

1
Document parsing

Preprocessing & structure detection

▾
raw PDF
→
H1 Chapter title
H2 Section heading
¶ Paragraph text block
⊞ Data table
⬜ Image / chart
H2 Next section
¶ Paragraph text block
Each PDF is decomposed into its individual structural elements: text blocks, tables, images, titles, and headings. The open-source tool Unstructured-IO is applied to reconstruct the logical document hierarchy using OCR, so all subsequent steps operate on organized, context-aware content rather than raw text.

The system searches all document elements using semantic similarity rather than keyword matching. Text is converted into numeric vector representations, meaning a query for "targets" also surfaces passages mentioning "goals" or "commitments". This allows for more comprehensive retrieval of relevant content, even when different terminology is used across documents.

Using large language models, the system extracts exact quotes from relevant passages, preserving the original wording and a link to the source page. A verification step then checks that each extracted quote is found verbatim in the original document, preventing the extraction of hallucinated text.

An efficient general knowledge LLM (GPT-4o-mini) categorizes each quote using a taxonomy defined by the analyst team. Learning in-context from detailed definitions and examples, the model distinguishes between sectors, targets from measures, mitigation from adaptation, and flags conditional commitments that depend on external support.
